# Marginote reading sample

This sample has an English interface guide, English notes, an original SVG illustration, and Latin Lorem ipsum passages for scrolling. It includes a text card, an image card, a mixed card, and an ordinary Markdown note. It contains no Obsidian profile, account information, plugin bundle, or workspace state.

1. Copy the `Marginote Demo` folder into a test vault, or open this directory as a new vault.
2. Install and enable Marginote in that vault.
3. Open **Marginote Demo / Read without losing your place** in Reading View.
4. Move beside or below **watching someone work**, **a small visual study**, or **an illustrated note** to see a card follow your pointer. Click the linked phrase to keep its card open; press Escape to close it.
5. To preview **your reading journal**, choose **Ordinary note links only** or **Both** under **Settings → Marginote → Preview content**.
6. Scroll through **Follow a thought** and **Make room for detail**, then open **return to the observation** near the end. The varied Lorem ipsum paragraphs provide reading space without repeated numbered filler.

The default automatic preview is **Near text · follows pointer** in Reading View and Live Preview. Move within 300 pixels beside or below a link, inside the same note pane, to open its preview. Use a mouse or trackpad in a window at least 768 pixels wide. Choose **Over link · stays in place** for a stationary card that opens only when you pause directly over its link, or **Off** for explicit opening only. Existing saved choices are preserved when upgrading.

The card notes use regular Markdown with `marginote-card`, `marginote-id`, and `marginote-kind` frontmatter. The journal is an ordinary note without card metadata. Images use local wiki embeds. The sample files can be read and edited without Marginote.

The real-app demo recorder imports these same files into its isolated QA vault. If the folder name already exists, it creates a numbered folder and updates only the copied link prefixes and card IDs. It never overwrites a previous sample.

The SVG and example notes were created for this repository. The scrolling text uses conventional Lorem ipsum filler. The files are covered by the repository's MIT license.
