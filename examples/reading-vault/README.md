# Marginote reading sample

This small sample contains original English notes and an original SVG illustration. It includes a text card, an image card, a mixed card, and an ordinary Markdown note. It contains no Obsidian profile, account information, plugin bundle, or workspace state.

1. Copy the `Marginote Demo` folder into a test vault, or open this directory as a new vault.
2. Install and enable Marginote in that vault.
3. Open **Marginote Demo / Read without losing your place** in Reading View.
4. Hover over **watching someone work**, **a small visual study**, or **an illustrated note** to open a card. Click a card to pin it; press Escape to close it.
5. To preview **your reading journal**, choose **Ordinary note links only** or **Both** under **Settings → Marginote → Preview content**.

The default automatic preview is **On hover**. **Near the text** is an optional setting that opens nearby cards as the pointer moves through the surrounding text. These modes are intentionally different.

The card notes use regular Markdown with `marginote-card`, `marginote-id`, and `marginote-kind` frontmatter. The journal is an ordinary note without card metadata. Images use local wiki embeds. The sample files can be read and edited without Marginote.

The real-app demo recorder imports these same files into its isolated QA vault. If the folder name already exists, it creates a numbered folder and updates only the copied link prefixes and card IDs. It never overwrites a previous sample.
