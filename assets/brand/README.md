# Marginote icon

`marginote-icon.png` is original artwork generated for Marginote with the built-in image generation tool on September 19, 2026. The final PNG is 1254 × 1254 pixels with transparency. It depicts a paper note connected to a smaller annotation card; it does not use Obsidian's crystal mark or another product's logo.

Use this icon in the README and Community directory listing. Keep its proportions and preserve the transparent background. It is a brand asset, not a new toolbar control in the plugin.

## Generation brief

> A polished square app icon for Marginote, a reading and annotation plugin. A warm ivory upright page with a folded corner and two dark ink reading lines connects to a rounded terracotta annotation card through a dark elbow line and square endpoint. Use broad, readable silhouettes, softly dimensional paper forms, subtle shadows, and a quiet editorial stationery aesthetic. No letters, wordmark, face, existing brand symbols, border, or watermark.

The generation requested a pale sage background; the returned asset instead has a transparent background, which is retained for use on light and dark surfaces. No reference artwork was supplied. The original generated output is preserved separately from this project copy.
